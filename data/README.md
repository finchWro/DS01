# Katalog Danych (`data/`)

Katalog przeznaczony na zbiory danych wykorzystywane w projekcie.

> **Ważne:** Zgodnie z regulaminem (§5.2 i §6) dane surowe ani przetworzone **nie mogą być commitowane do repozytorium Git**.

## Podział katalogu:
- `raw/`: dane źródłowe w niezmienionej postaci pobrane z oficjalnego repozytorium.
- `processed/`: dane po wstępnym oczyszczeniu, podziale lub transformacjach.
